Publishing changes (every time)
  1. Make your edits in the tabs above.
  2. Click Export data.js (top right) — a file downloads.
  3. Go to your GitHub repo → open data.js → upload/replace with the new one → commit.
  4. Wait ~1 min, then hard-refresh your site (Ctrl/Cmd+Shift+R).
Adding product photos

Click Choose Photo on any product. The image is embedded directly into data.js, so you don't need to upload photos separately. Keep photos reasonably sized (under ~1MB each) so the file stays light — the tool warns you if one is large.

Safety net

If data.js is ever missing or broken, your site automatically falls back to its built-in defaults — it will never go blank. This admin also keeps a copy of your work in this browser.

Important

Keep admin.html private — don't link to it from your site menu. It's your control panel. (It also tells search engines not to index it.)
